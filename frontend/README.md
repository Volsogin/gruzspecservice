# Фронтенд — сайт ГРУЗСПЕЦСЕРВИС

React 18 + TypeScript + Vite. Перенесён из макета Claude Design (`*.dc.html`) с сохранением вёрстки один в один:
inline-стили макета живут в коде как строки (`s('…')` в `src/lib/css.ts`), hover/focus — классы в `src/index.css`.
Только тёмная тема, десктоп и мобильная версия (< 860 px — мобильная раскладка, < 1100 px — мобильная шапка
и нижняя панель «Позвонить / Вызвать мастера / Чат»).

## Запуск

```bash
make dev
```

```bash
make web
```

Первая команда — API на :8000, вторая (во втором терминале) — сайт на <http://localhost:5173> с прокси
`/api` и `/media` на API. Собрать (`frontend/dist/`) — `make web-build`; сайт + API одним процессом — `make preview`.
Нужен Node.js 18.18+.

## Страницы и блоки

| Маршрут | Что там | API |
|---|---|---|
| `/` | первый экран, лента услуг → форма нужного типа, форма заявки (6 типов, фото, согласие), зона выезда на карте 2ГИС, калькулятор, цифры, преимущества, марки, отзывы с кейсами «до/после», юрлицам, контакты | `/bootstrap`, `/forms/{type}`, `/leads`, `/dispatch/check`, `/geo/*`, `/calculator/*`, `/reviews`, `/cases/{id}` |
| `/order/:token` | статус заявки: шаги, история, сводка, фото, расчёт, «Получать статус в Telegram» | `/orders/{token}` (опрос раз в 30 с) |
| `/privacy` | политика ПДн | `/legal/privacy` |
| `*` | 404 | — |
| везде | чат-виджет: ИИ (поток SSE), подсказки, карточки расчёта/формы/карты/заявки, «Позвать оператора», живой оператор | `/chat/sessions/*` |

## Что изменено относительно макета
- Все данные — из API: контакты, услуги, цифры, преимущества, отзывы, рейтинг, марки, цены, зона выезда.
  Выдуманные в макете телефон, адрес и реквизиты убраны: реквизиты показываются, только если заполнены в админке.
- Карта: вместо заглушки — 2ГИС MapGL (зона 15 км, маркер СТО, выбор точки, поиск адреса, геолокация).
- Калькулятор считает на сервере (одна формула с оператором), расчёт прикрепляется к заявке (`estimate_id`).
- Форма: адрес у выезда/эвакуатора необязателен, если стоит точка на карте; вместо «2–3 дня» — «На этой неделе»
  (как в API); убран тип «Автобус» (его нет в прайсе); размер парка — диапазоны.
- Преимущества 5–9: вместо пометки дизайнера «цифра в стиле 1–4» — тонкая цифра в стиле блока.
- Добавлено: skip-link, `aria-*` у вкладок/переключателей/диалогов, `:focus-visible`, `prefers-reduced-motion`.
- Картинки сжаты в WebP: 5,7 МБ → 0,5 МБ.
