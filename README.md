# ГРУЗСПЕЦСЕРВИС — сайт грузового автосервиса

Проект хакатона: сайт для ООО «ГРУЗСПЕЦСЕРВИС» (Саратов) — ремонт и обслуживание грузовиков, полуприцепов и
спецтехники на СТО и с выездом к месту поломки, круглосуточно.

## Задумка

**Цель сайта** — превратить визит в заявку (вызов мастера, запись на ремонт, запрос запчасти) и вызвать доверие.

**Для кого:** водители-частники и владельцы 1–5 грузовиков, у которых машина встала прямо сейчас, и
логистические компании с автопарками, которым нужен надёжный подрядчик по договору.

**Ключевые идеи:**
- **Одна услуга — одна форма.** Услуги показаны горизонтальной лентой; выбор карточки прокручивает к форме,
  которая уже знает тип заявки и показывает только нужные поля: для выезда — точку на карте, для эвакуатора —
  «куда везти», для запчастей — VIN, для юрлиц — ИНН и размер парка.
- **Заявка не теряется и видна клиенту.** После отправки — экран подтверждения со ссылкой на заказ; каждый
  статус («Принята», «Мастер выехал», «В работе», «Готово») приходит клиенту на e-mail и в Telegram.
- **Оператору — минимум действий.** Заявка приходит дежурным операторам в Telegram карточкой с телефоном, точкой
  в 2ГИС и фото. Кто первым нажал «Беру» — ответственный; статусы меняются кнопками прямо в Telegram.
- **«Выезд за 30 минут» честно.** Круг на карте показывает, где обещание реально выполнимо; дальше по области —
  «приедем, время уточнит диспетчер».
- **Обратная связь — через чат.** ИИ-помощник отвечает про услуги, цены и выезд и без уговоров зовёт живого
  оператора, если клиент просит.
- **Доверие:** статистика, отзывы с переходом на Яндекс и 2ГИС, кейсы «до/после» в раскрытии отзыва.

## Функционал

### Заявки
- 6 типов форм: ремонт на СТО, выезд мастера, эвакуатор, запчасти, корпоративное обслуживание, обратный звонок.
  Поля описаны схемой на сервере: фронт рисует форму по схеме, сервер проверяет по ней же.
- Проверки: телефон с маской +7 (приводится к `+7XXXXXXXXXX`), обязательное согласие на обработку ПДн
  (сохраняются факт, время и версия текста), ИНН с контрольной суммой, VIN, точка на карте.
- До 5 фото: тип проверяется по содержимому, геометки и EXIF удаляются, делаются превью.
- Защита от дублей и спама: `Idempotency-Key`, скрытое поле-ловушка, проверка времени заполнения, лимиты по IP
  и телефону.
- Каждой заявке — номер (`GS-1001`) и секретная ссылка `/order/{token}` со статусом, шагами и историей.

### Уведомления и работа оператора
- Операторы регистрируются в боте по коду-приглашению; новые заявки приходят дежурным (`/smena`) в личку.
  «✋ Беру» — первый нажавший становится ответственным, у остальных карточка меняется на «Ответственный: …».
  Никого нет на смене — заявки идут в запасной общий чат. Плюс e-mail оператору.
- Клиенту: ссылка на заказ сразу после отправки; по желанию — e-mail и Telegram на каждую смену статуса.
- Telegram-бот для клиента: подписка по кнопке с сайта, по @username из формы или по телефону + номеру заявки
  («Найти заявку»); «Мои заявки», вопрос оператору (ответ приходит в бот), отмена до выезда мастера.
- Отправка через очередь (outbox) с повторами: сбой почты или Telegram не ломает приём заявки.
- Админка (SQLAdmin): заявки и смена статусов, история, услуги, цены, отзывы, кейсы, настройки, очередь
  уведомлений, диалоги чата.

### Выезд и карта
- Зона «30 минут» — круг вокруг СТО (по умолчанию 15 км) для карты 2ГИС, проверка точки клиента:
  внутри зоны / по области / вне зоны.
- В заявке на выезд и эвакуатор — точка и адрес, у оператора — ссылка «открыть в 2ГИС».
- Прокси к геокодеру 2ГИС (адрес ↔ координаты) с кэшем.

### Калькулятор
- Марка + тип техники + вид работ + срочность/выезд → «от N ₽» с расшифровкой (цены условные, правятся в админке).
- Расчёт можно приложить к заявке — оператор увидит его.

### ИИ-ассистент
- OpenRouter с вызовом инструментов (услуги, контакты, расчёт цены, проверка зоны, создание заявки, оператор),
  ответ стримится по SSE, тематические подсказки-кнопки.
- Без ключа, при сбое сети или исчерпании дневного бюджета — режим FAQ по базе знаний: бот не падает.
- Передача оператору только по просьбе клиента: заявка с расшифровкой диалога, живой чат через Telegram
  (ответ оператора приходит на сайт).

### Отзывы и доверие
- 10 демо-отзывов, средний рейтинг, кнопки «Отзывы на Яндексе / 2ГИС», кейсы с фото «до/после».
- Блок доверия: стаж, клиенты, гарантия, режим работы 24/7 с текущим статусом «открыто».
- Первый экран — одним запросом `/bootstrap` с кэшем, ETag и сжатием brotli/gzip.

## Быстрый старт

```bash
cp .env.example .env
```

```bash
make dev
```

Запуск без Docker (нужен только [uv](https://docs.astral.sh/uv/)): SQLite, демо-данные, API на
<http://localhost:8000>, Swagger на `/docs`, админка на `/admin`. С PostgreSQL в Docker — `make up`.
Все команды — `make help`. Подробно (установка на Linux Mint, ключи, Telegram, 2ГИС) — в
[docs/README.md](docs/README.md).

## Стек

Python 3.12 · FastAPI · Pydantic v2 · SQLAlchemy 2 (async) + Alembic · PostgreSQL / SQLite · SQLAdmin · httpx ·
Pillow · OpenRouter · Telegram Bot API · 2ГИС. Качество: ruff, mypy `--strict`, pytest (113 тестов), pre-commit,
GitHub Actions.
